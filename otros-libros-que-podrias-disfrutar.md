# Sección Final: Lecturas Adicionales

## Otros Libros que Podrías Disfrutar

Si te ha interesado este libro, te recomendamos las siguientes lecturas complementarias de Packt:

---

### Sección 1: AI Networking Cookbook

**Autor:** Eric Chou  
**ISBN:** 978-1-80580-799-5

- Comprende el panorama de los LLMs de IA y los parámetros clave para tareas de redes.
- Crea scripts habilitados para OpenAI para flujos de trabajo diarios de ingeniería de redes.
- Domina técnicas de ingeniería de prompts para obtener mejores salidas de IA.
- Construye LLMs locales utilizando Ollama para aplicaciones de red.
- Encadena modelos de lenguaje con LangChain para soluciones de red complejas.
- Desarrolla frontends para aplicaciones de IA utilizando el framework Streamlit.
- Diseña backends robustos para aplicaciones de IA en redes.
- Construye un copiloto de red de extremo a extremo integrando todas las técnicas aprendidas.

---

### Sección 2: Agentic AI for Platform Engineering

**Autores:** Tiago Miguel Reichert, Lucas Soriano Alves Duarte, Jaime Nagase  
**ISBN:** 978-1-80638-665-9

- Integra IA Generativa y RAG en plataformas internas de desarrolladores (IDP).
- Construye interfaces conversacionales para la generación de Infraestructura como Código (IaC).
- Implementa observabilidad impulsada por IA con autorreparación agéntica (*self-healing*).
- Diseña y despliega sistemas multiagente para operaciones autónomas.
- Aplica MCP (*Model Context Protocol*) para conectar herramientas de IA con sistemas de conocimiento organizacional.
- Asegura plataformas mejoradas con IA frente a inyecciones de prompts y amenazas de identidad.
- Gobierna la IA agéntica con patrones *Human-in-the-Loop* y marcos de cumplimiento normativo.
- Evalúa decisiones de desarrollo propio (*build*) frente a adquisición (*buy*) para herramientas de plataformas de IA.
